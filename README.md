# Death Sound Alerts for Raids

A RuneLite plugin that plays a customizable sound whenever another player dies during the Theatre of Blood.

## Features

* Theatre of Blood death alerts
* Multiple built-in alert sounds
* Sound selection can be changed from the RuneLite configuration
* Sounds are bundled with the plugin

## Supported Raids

### Theatre of Blood

Fully supported.

### Chambers of Xeric

Not currently supported.

### Tombs of Amascut

Not currently supported.

## Alert Sounds

* Default
* Airhorn
* Meow
* Old Man
* Quack
* Gunshot

More raid support may be added in future updates.
